## 2. BK-3 モデル勢力図スナップショット

### 2-1. 何のための付録か

本書は `evaluation_date` 付きの時変情報を扱う本です。モデルの価格と性能は本文の各エントリでも触れますが、**「その時点で、どの価格帯に、どのモデルが、どの序列でいたか」を横並びで見る場所**が本文にはありません。

この付録は、**過去の各時点を、そのままの姿で標本にして並べる**ものです。読者が「2024 年にはこの値段でこの性能だったのか」と体感できることを狙います。買い物ガイドではありません。**刷った瞬間に古くなる前提**で、歴史記録として作ります。

### 2-2. 絶対に守る原則 — 四半期をまたいで性能を比べない

**この付録で通年比較してよいのは価格だけです。**

- **価格は比較できます。** $/Mtok は年をまたいでも同じ物差しです
- **性能は比較できません。** ベンチマークは飽和して差し替えられます。Vals Index 自体が 2026-08 に 2.0 として作り直されており、構成ベンチもバージョン付き（Finance Agent v2 / Terminal-Bench 2.1 など）で入れ替わります。2025 年の 60% と 2026 年の 60% は**別の物差しの 60%** です

したがって性能は **「その四半期の中での相対順位」としてのみ**扱い、スコアを折れ線で繋いだり、四半期をまたいで点数を並べたりしません。

これは本書が [J-114 グッドハートの法則](../content/entries/term_general/) と E 章（ベンチマーク汚染）で扱っている問題そのものです。**自分の付録でそれを踏まないこと。**

### 2-3. 価格帯（固定・2026-09-04 著者決定）

出力トークンの $/Mtok で 3 帯に切ります。**境界値は全四半期で固定します。**

| 帯 | 境界（出力 $/Mtok） |
|---|---|
| フロンティア | **$15 以上** |
| ミドルティア | **$1 以上 15 未満** |
| 激安 | **$1 未満** |

**境界を固定するのがこの付録の肝です。** 帯を固定して四半期を追うと、「**激安帯に降りてくるモデルの顔ぶれが、数年前のフロンティア級になっている**」ことが表として見えます。「コストは下がり、性能は上がる」を、スコアの折れ線ではなく**帯の中身の入れ替わり**として描くのが、2-2 の原則に反しない唯一の表現です。

### 2-4. 各行に載せる項目

| 項目 | 備考 |
|---|---|
| モデル名 | 誌面表記に合わせる |
| 提供元 | 企業名（C 章とリンク） |
| 入力 $/Mtok | 標準価格。キャッシュ割引・バッチ割引は含めない |
| 出力 $/Mtok | 帯の判定に使う値 |
| その四半期内の順位 | Vals Index による。**存在しない四半期は空欄**（2-5） |
| オープンウェイトか | ◯ / ✕ |

**「標準価格」の定義**（2026-09-05 著者了承）。**その四半期に実際に適用されていた公表価格**を採ります。

- **含めない**: キャッシュヒット割引、バッチ割引、Flex 等の低優先度枠、DeepSeek のオフピーク料金。これらは**使い方によって効いたり効かなかったりする条件付き割引**なので、帯の判定に使うと同じモデルが帯をまたいでしまいます
- **含める**: 期間限定の公表価格（Gemini 3.8 Flash の 2026 年内価格、GPT-5.6 Sol の販促価格、GLM-5.3-Flash の 50% 引きなど）。これは**誰が使っても同じ**で、その四半期に現に払っていた額です。スナップショットは「当時の姿」を残すものなので、こちらを採ります
- 定価が別にある場合は `source` 欄に併記します

ページ下に注記を必ず入れます: **「順位は同時点内の相対です。四半期をまたいで点数を比べないでください。」**

### 2-5. 順位の根拠と、遡れる範囲の限界

順位の根拠は **Vals Index** 一本にします（2026-09-04 著者決定）。複数ベンチの併記はしません。

ただし **Vals Index は全期間には存在しません。**

- Vals AI の最初期のリーダーボードが 2024 年
- **Vals Index 2.0 は 2026-08 に作り直し**。それ以前は 1.x
- 最古の対象四半期（2024 Q1）には Vals Index が存在しない見込み

そこで **濃淡をつけます**。

- **Vals Index が存在する四半期**: 価格帯 ＋ 順位
- **存在しない四半期**: 価格帯と顔ぶれのみ（順位欄は空。「当時この帯にいたのはこの顔ぶれ」だけを示す）

順位が無くても、価格帯の入れ替わりという主眼は成立します。**無い順位を別のベンチで代用して埋めないこと。**物差しが混ざります。

### 2-5b. 過去の順位をどう取るか（2026-09-05 追加、要著者確認）

Vals AI は**過去の版の表を残しています。**リーダーボード上の版セレクタから、次の 4 つが選べます。

| 版 | 表の更新日 | 掲載数 | 主な変更 |
|---|---|---|---|
| Version 1 | 2026-05-06 | 35 | 初版（CorpFin / Finance Agent / CaseLaw / SWE-Bench / Terminal Bench） |
| Version 1.1 | 2026-05-28 | 19 | Vibe Code Bench 追加、Law（CaseLaw）廃止 |
| Version 1.2 | 2026-08-11 | 45 | coding を Terminal-Bench 2.1 に、Finance Agent v2 に差し替え |
| Version 2 | 2026-09-04 | 54 | EMB / Code Migration / Legal Research / HLAB を追加、SWE-Bench 廃止 |

そこで、**各四半期には「その時点で現行だった版」の表を使い、その四半期末までに提供が始まっていたモデルだけに絞って順位を振り直します。**

| 四半期 | 使う版 |
|---|---|
| 2026 Q3 | Version 2 |
| 2026 Q2 | Version 1.2 |
| 2026 Q1 | Version 1 |
| 2025 Q4 | Version 1 |
| 2025 Q3 以前 | **なし（順位は空欄）** |

**この方法の限界を隠さないこと。**版の表は「その版の物差しで、公表時点までに測った結果」であって、「その四半期末に公表されていた表」そのものではありません。四半期末より後に測られた分も混ざります。**採れるのは物差しの同一性までで、測定時点の同一性は採れません。**

だからこそ §2-2 が効きます。**順位は四半期の中でしか使いません。**四半期をまたいでスコアや順位を並べないでください。

2025 Q3 以前は Vals Index 自体がまだありません（www.vals.ai のリーダーボードの記録は 2025-10 が最古）。仕様どおり空欄にします。

### 2-7. 収録するモデルの基準 — ポジションを持つものだけ

**全モデルを網羅しません。**各帯で「何らかのポジションを発揮している」モデルだけを載せます（2026-09-03 著者決定）。

- 帯の中で当時トップクラスだった
- その帯の価格を切り下げた（値付けで位置を作った）
- オープンウェイトとして帯の性格を変えた

**この線に乗らないものは載せません。**網羅性より、読者が「この帯はこういう場所だった」と掴めることを優先します。判断に迷ったら落とす。

**ポジションはあるのに公式価格が取れないモデルは、行を残して価格を空欄にします**（2026-09-05 著者決定）。落としません。「当時この位置にいたが、提供元が価格を公表していなかった（あるいは今は辿れない）」ということ自体が記録だからです。誌面では帯に置けないので、**帯の外に注記として置きます**。

2026 Q3 の Muse Spark 1.3（Meta）がこれに当たります。Vals Index 8 位と高い位置にいますが、提供元の公式価格ページが見つかりませんでした。

## 3. データの取得

### 3-1. 一次情報で取る

**まとめブログ・SEO 記事は使いません**（2026-09-03 著者決定）。価格は各社の公式価格ページ、順位は Vals AI の公表値を正とします。出典メモには必ず `checked YYYY-MM-DD` を残します。

### 3-2. 収集できる環境・できない環境

**リモートの Claude Code からは集められません。** 2026-09-04 に実測したところ、**試した公式ドメインがすべて 403 で遮断されていました**（プロキシのドメインポリシー。WebFetch・curl とも同じ）。動くのは WebSearch（検索結果の要約）だけですが、これはまとめ記事由来なので §3-1 により使えません。

遮断を確認したドメイン: `vals.ai` / `anthropic.com` / `openai.com` / `platform.openai.com` / `ai.google.dev` / `docs.cloud.google.com` / `api-docs.deepseek.com` / `docs.x.ai` / `z.ai` / `platform.moonshot.ai` / `wikipedia.org`。

**ローカル環境（著者の PC 上の Claude Code）からは集められます。** 2026-09-05 に同じドメインを実測し、**すべて取得できました**。2026 Q3 のデータはこの方法で埋めています。

ただし **Vals Index の順位表は JavaScript で描画されるため、`curl` では取れません。**ブラウザで開いて読む必要があります（本リポジトリでは Browser ペインを使用）。価格ページは `curl` で取れます。

**したがって、この付録のデータ収集はローカル環境で行ってください。**リモートセッションでやろうとすると §3-1 に違反せずには進みません。

過去の四半期については、当時の価格表・当時の順位ともに遡って取るのが難しくなります。**取れなかった項目は推測で埋めず、空欄のまま残してください。**

### 3-3. データの置き場所

[ledgers/model_snapshots.csv](../ledgers/model_snapshots.csv) を単一の元データにします。1 行 1 モデル 1 四半期。

| 列 | 意味 |
|---|---|
| `quarter` | `2026Q3` の形式 |
| `tier` | `frontier` / `middle` / `budget`。`output_usd_per_mtok` から機械的に決まる（>=15 / >=1 / <1） |
| `model` / `vendor` | 誌面表記 |
| `input_usd_per_mtok` / `output_usd_per_mtok` | 標準価格。キャッシュ・バッチ割引を含めない |
| `vals_index_rank` | その四半期内の順位。無い四半期は空欄 |
| `open_weights` | ◯ / ✕ |
| `source` / `checked` | 一次情報の URL または文書名と、確認日 |

**空欄は「未取得」を意味します。**推測で埋めないこと。

### 3-4. 一次情報どうしが食い違ったときは、提供元の公式ページを正とする

2026 Q3 の収集で実際に起きました。**Claude Sonnet 5 の価格が、Anthropic 公式ページでは $2/$10、Vals AI の表では $3/$15** と食い違っていました。帯の境界が $15 なので、どちらを採るかで**帯が変わります**（ミドル / フロンティア）。

**価格は提供元の公式ページを正とします。**Vals AI は順位の一次情報ではありますが、価格については提供元の写しにすぎず、更新が遅れることがあります。食い違いを見つけたら `source` 欄に併記して残してください。
