## 2. BK-3 モデル勢力図スナップショット

### 2-1. 何のための付録か

本書は `evaluation_date` 付きの時変情報を扱う本です。モデルの価格と性能は本文の各エントリでも触れますが、**「その時点で、どの価格帯に、どのモデルが、どの序列でいたか」を横並びで見る場所**が本文にはありません。

この付録は、**過去の各時点を、そのままの姿で標本にして並べる**ものです。読者が「2024 年にはこの値段でこの性能だったのか」と体感できることを狙います。買い物ガイドではありません。**刷った瞬間に古くなる前提**で、歴史記録として作ります。

### 2-2. 絶対に守る原則 — 四半期をまたいで性能を比べない

**この付録で通年比較してよいのは価格だけです。**

- **価格は比較できます。** $/Mtok は年をまたいでも同じ物差しです
- **性能は比較できません。** ベンチマークは飽和して差し替えられます。Vals Index 自体が 2026-08 に 2.0 として作り直されており、構成ベンチもバージョン付き（Finance Agent v2 / Terminal-Bench 2.1 など）で入れ替わります。2025 年の 60% と 2026 年の 60% は**別の物差しの 60%** です

したがって性能は **「その四半期の中での相対順位」としてのみ**扱い、スコアを折れ線で繋いだり、四半期をまたいで点数を並べたりしません。

これは本書が [J-114 グッドハートの法則](../content/entries/term_general/) と E 章（ベンチマーク汚染）で扱っている問題そのものです。**自分の付録でそれを踏まないこと。**

### 2-3. 価格帯（固定・2026-09-04 著者決定）

出力トークンの $/Mtok で 3 帯に切ります。**境界値は全四半期で固定します。**

| 帯 | 境界（出力 $/Mtok） |
|---|---|
| フロンティア | **$15 以上** |
| ミドルティア | **$1 以上 15 未満** |
| 激安 | **$1 未満** |

**境界を固定するのがこの付録の肝です。** 帯を固定して四半期を追うと、「**激安帯に降りてくるモデルの顔ぶれが、数年前のフロンティア級になっている**」ことが表として見えます。「コストは下がり、性能は上がる」を、スコアの折れ線ではなく**帯の中身の入れ替わり**として描くのが、2-2 の原則に反しない唯一の表現です。

### 2-4. 各行に載せる項目

| 項目 | 備考 |
|---|---|
| モデル名 | 誌面表記に合わせる |
| 提供元 | 企業名（C 章とリンク） |
| 入力 $/Mtok | 標準価格。キャッシュ割引・バッチ割引は含めない |
| 出力 $/Mtok | 帯の判定に使う値 |
| その四半期内の順位 | Vals Index による。**存在しない四半期は空欄**（2-5） |
| オープンウェイトか | ◯ / ✕ |

ページ下に注記を必ず入れます: **「順位は同時点内の相対です。四半期をまたいで点数を比べないでください。」**

### 2-5. 順位の根拠と、遡れる範囲の限界

順位の根拠は **Vals Index** 一本にします（2026-09-04 著者決定）。複数ベンチの併記はしません。

ただし **Vals Index は全期間には存在しません。**

- Vals AI の最初期のリーダーボードが 2024 年
- **Vals Index 2.0 は 2026-08 に作り直し**。それ以前は 1.x
- 最古の対象四半期（2024 Q1）には Vals Index が存在しない見込み

そこで **濃淡をつけます**。

- **Vals Index が存在する四半期**: 価格帯 ＋ 順位
- **存在しない四半期**: 価格帯と顔ぶれのみ（順位欄は空。「当時この帯にいたのはこの顔ぶれ」だけを示す）

順位が無くても、価格帯の入れ替わりという主眼は成立します。**無い順位を別のベンチで代用して埋めないこと。**物差しが混ざります。

### 2-6. 対象期間と刻み

対象は **2024 Q1 以降**（2026-09-04 著者決定）。2026 Q3 まで 11 四半期あり、全部を四半期刻みで載せると巻末付録として重すぎます。

**推奨（要著者確認）**: 直近 4〜6 本を四半期刻み、それ以前を半期または年刻みに間引く。古い時期ほど動きが遅いので情報量としても釣り合います。

### 2-7. 収録するモデルの基準 — ポジションを持つものだけ

**全モデルを網羅しません。**各帯で「何らかのポジションを発揮している」モデルだけを載せます（2026-09-03 著者決定）。

- 帯の中で当時トップクラスだった
- その帯の価格を切り下げた（値付けで位置を作った）
- オープンウェイトとして帯の性格を変えた

**この線に乗らないものは載せません。**網羅性より、読者が「この帯はこういう場所だった」と掴めることを優先します。判断に迷ったら落とす。

## 3. データの取得

### 3-1. 一次情報で取る

**まとめブログ・SEO 記事は使いません**（2026-09-03 著者決定）。価格は各社の公式価格ページ、順位は Vals AI の公表値を正とします。出典メモには必ず `checked YYYY-MM-DD` を残します。

### 3-2. 既知の制約

**Claude Code の実行環境（リモート）から vals.ai へ到達できません。** WebFetch も curl も 403（プロキシのドメインポリシー）で弾かれます。2026-09-04 時点で確認済み。

そのため役割分担が要ります。

- **価格**: 各社の公式価格ページから取得可能。AI 側で対応できます
- **順位**: 著者が Vals AI の表を参照して渡すか、貼り付ける

過去の四半期については、当時の価格表・当時の順位ともに遡って取るのが難しくなります。**取れなかった項目は推測で埋めず、空欄のまま残してください。**
