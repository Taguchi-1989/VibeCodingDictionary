# MiniMax

## tagline

文章・音声・動画を 1 社でそろえる、上海発の AI 企業です。

<!-- ━━━━━━━━ 左ページ ━━━━━━━━ -->

## 何をしてくれるか

中国・上海の AI 企業です。文章とコーディング向けの LLM「MiniMax M 系」、動画生成の「Hailuo（海螺）」、音声合成などを開発しています。2026-01 に香港で上場しました。

## どこで出会うか

動画生成 Hailuo の話題や、オープンモデルの比較記事、Artificial Analysis のリーダーボードで名前が挙がります。中国の LLM 専業企業の上場例として紹介する記事にも登場します。

## メイン図

### 図の狙い

文章・動画・音声の 3 分野を 1 社が手がけている構図を示し、「動画の会社」という入口から LLM 企業としての顔へつなげます。

## 会話での使い方例

「MiniMax は動画の Hailuo で知りましたが、LLM も出していますよね。」

<!-- ━━━━━━━━ 右ページ ━━━━━━━━ -->

## この用語の見どころ

### 1. 役割

文章・音声・動画のモデルを 1 社で開発する企業です。

### 2. うれしさ

用途の違うモデルを同じ会社の製品でそろえられます。

### 3. 注意点

分野ごとにモデル名が違い、混同しやすいです。

### 4. どこで役立つか

動画生成や長い文脈の LLM を探すときの候補です。

### 5. はじめに

2021 年創業、上海、代表モデル M 系と Hailuo を押さえます。

### 6. 深掘り先

Moonshot AI、Z.ai、MoE

## 開発フローでの位置（必須）

1. 情報収集 — Hailuo や M 系の話題を記事で確認する
2. モデル選定 — 文章・動画など用途別に候補を絞る
3. 条件確認 — 対応する入力、文脈の長さ、ライセンスを読む
4. 試用 — API やアプリで小さな題材を試す
5. 導入判断 — 品質・費用・データの扱いを見て採否を決める
