# Alibaba

## tagline

Qwen を開発する、杭州発のネット通販大手です。重みを公開するモデルが中心です。

<!-- ━━━━━━━━ 左ページ ━━━━━━━━ -->

## 何をしてくれるか

中国・杭州の IT 企業です。クラウド部門 Alibaba Cloud が、LLM（大規模言語モデル）の Qwen（通義千問）を開発しています。小型から大型まで、重みを公開したモデルを配っています。

## どこで出会うか

オープンモデルの比較記事や、Artificial Analysis のリーダーボードで、Qwen の開発元として名前が挙がります。手元で動かせる小型モデルを探すときにも出会います。

## メイン図

### 図の狙い

「ネット通販の会社が、配る AI の大手でもある」という立ち位置を、会社・クラウド部門・Qwen の 3 段で掴んでもらいます。

## 会話での使い方例

「Qwen は Alibaba のモデルで、小型を手元で動かせますよね。」
