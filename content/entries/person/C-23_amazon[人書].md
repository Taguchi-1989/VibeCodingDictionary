# Amazon

## tagline

クラウド AWS を軸に、自社と他社のモデルを貸す米国の大手企業です。

<!-- ━━━━━━━━ 左ページ ━━━━━━━━ -->

## 何をしてくれるか

1994 年にジェフ・ベゾス氏が創業した米国の企業です。クラウドの AWS が AI の窓口で、Amazon Bedrock を通じて自社モデルの Nova や Anthropic など他社のモデルをまとめて借りられます。

## どこで出会うか

AWS 上で AI を組み込む場面や、Bedrock のモデル一覧、年末の re:Invent の発表記事で名前が出ます。Anthropic への大口出資者として語られることもあります。

## メイン図

### 図の狙い

Amazon が「自分でも作るが、他社のモデルを貸す場所」という顔を持つことを、AWS・Bedrock・各社モデルの並びで掴んでもらいます。

### B. 登場シーン（figure_type: structure）

- シーン1: AWS の管理画面で Bedrock のモデル一覧から使うモデルを選ぶ場面
- シーン2: Nova など自社モデルと、Anthropic など他社モデルが同じ窓口に並ぶ場面
- シーン3: re:Invent の発表を伝えるニュースで社名が出る場面
- 並べる基準: 読者が Amazon を「通販」以外の顔で知る入口

## 会話での使い方例

「Amazon は Bedrock で Claude も Nova も借りられるのが特徴ですよね。」

## 開発フローでの位置（必須）

1. 情報収集 — Bedrock で借りられるモデルを一覧で確認する
2. モデル選定 — Nova や他社モデルを比べて候補を絞る
3. 利用判断 — 提供状況・料金・データの扱いを確かめる
4. 導入・活用 — AWS 上のアプリから API で呼び出す
5. 運用 — モデルの更新や提供終了の告知を追う
