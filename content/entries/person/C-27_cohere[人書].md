# Cohere

## tagline

企業向けに特化した、トロント発の AI 企業です。Command を開発しています。

<!-- ━━━━━━━━ 左ページ ━━━━━━━━ -->

## 何をしてくれるか

カナダ・トロントの AI 企業です。一般向けチャットではなく企業向けに絞り、LLM（大規模言語モデル）の Command や、検索用の Embed・Rerank を提供しています。自社の環境に置いて動かせる点が売りです。

## どこで出会うか

オープンモデルの比較記事や、社内文書を検索して答える RAG の解説で、Command の開発元として名前が挙がります。企業向け AI の選定でも出会います。

## メイン図

### 図の狙い

「一般向けのチャットではなく、企業の中に置いて動かす AI」という立ち位置を、会社・モデル・企業の環境の 3 段で掴んでもらいます。

## 会話での使い方例

「Cohere は企業向けで、RAG に強い Command が有名ですよね。」

## この用語の見どころ

### 1. 役割

企業の環境で動かす前提の AI を作る会社です。

### 2. うれしさ

社内データを外に出さず使う道を探せます。

### 3. 注意点

一般向けのチャットアプリは中心ではありません。

### 4. どこで役立つか

社内文書の検索・要約を AI に任せたいときです。

### 5. はじめに

2019 年創業、トロント、代表モデル Command の 3 点を押さえます。

### 6. 深掘り先

Command 系、RAG、Embedding

## 開発フローでの位置（必須）

1. 課題整理 — 社内文書の検索や要約など、任せたい業務を決める
2. モデル選定 — Command や Embed・Rerank を候補に挙げる
3. 条件確認 — 動かす場所・ライセンス・データの扱いを読む
4. 試用 — 社内文書を使い、検索して答える流れを試す
5. 導入判断 — 品質・費用・運用の手間を見て採否を決める
