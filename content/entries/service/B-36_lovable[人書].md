# Lovable

## tagline

自然文の指示だけで画面・データベース・認証まで一括生成するサービスです。

<!-- ━━━━━━━━ 左ページ ━━━━━━━━ -->

## 何をしてくれるか

作りたいアプリを日本語や英語の自然文で伝えると、画面・データベース・ログイン機能・その配線までまとめて生成します。ブラウザで完結し、ターミナルを開く必要がありません。

## どこで出会うか

「ノーコードでアプリまで作れた」という体験談で SNS や紹介記事によく登場します。Bolt.new や v0 と並べて比較される場面もあります。

## メイン図

### 図の狙い

要望を伝えるだけで画面・データベース・認証までが一気に組み上がる様子を示します。

### C. 概念図（figure_type: workflow）

- 中心に置く概念: Lovable のチャット画面
- 周辺の要素: 自然文の要望 → 画面生成 → データベース・認証の自動配線 → 公開リンク
- 関係の描き方: 左から右への矢印フロー、各ステップに人物の吹き出しを添える

## 会話での使い方例

「Lovable なら画面もデータベースも一気に作ってくれますよ。」

## この用語の見どころ

### 1. 役割

自然文の指示でフルスタックアプリを生成するサービスです。

### 2. うれしさ

フロントもバックエンドも自分で配線せずに済みます。

### 3. 注意点

生成コードの中身把握には見直しの手間がかかります。

### 4. どこで役立つか

アイデア段階の試作やデモ作りに向いています。

### 5. はじめに

サイトを開き作りたいものを日本語で書くだけです。

### 6. 深掘り先

Supabase、Bolt.new、v0

## 開発フローでの位置（必須）

1. 要望入力 — 作りたいアプリの内容を自然文で伝えます
2. 自動生成 — 画面・データベース・認証まで組み立てます
3. プレビュー確認 — ブラウザ上で動作を見ながら直します
4. 公開 — そのまま公開リンクを発行して共有します

## コミュニティ補完メモ

- Bolt.new（B-11）との住み分け：どちらもブラウザで動くフルスタック生成サービスですが、Bolt.new は WebContainers でブラウザ内に Node.js を内蔵する点が独自です。Lovable はバックエンドの実体を Supabase 等の外部サービスへ配線する構成が中心になります
- v0（B-9）との住み分け：v0 は React コンポーネント生成に特化します。Lovable は画面だけでなくデータベースや認証まで含めたアプリ全体の面倒を見ます
- Supabase（B-29）との住み分け：Lovable が生成するバックエンドの実体（データベース・認証）は Supabase 上で動くことが多く、Supabase 自体の機能詳細は B-29 で扱います
