## tagline

Google 製のオープンソース AI エージェントです。ターミナルで動きます。

<!-- ━━━━━━━━ 左ページ ━━━━━━━━ -->

## 何をしてくれるか

ターミナルから使えるオープンソース版の AI コーディングエージェントです。ファイルの読み書きやコマンド実行、Web 検索、MCP 連携までひとつの対話でこなします。

## どこで出会うか

Claude Code（B-7）や Codex（B-8）と並んで比較記事に登場する、無料で試しやすいターミナル型エージェントです。Google アカウントでログインするだけで、無料枠から使い始められます。

## メイン図

### 図の狙い

ターミナルでのログインから指示、MCP 連携までの流れを示し、無料で使い始められる点を伝えます。

### B. 登場シーン（figure_type: structure）

- シーン1: 開発者がターミナルで `gemini` を起動し、Google アカウントでログインする
- シーン2: 自然言語で指示すると、ファイル編集やシェル実行、Web 検索を自律的にこなす
- シーン3: MCP 経由で外部ツールとも接続し、Claude Code や Codex と並ぶ選択肢になる
- 並べる基準: ログイン → 指示 → 拡張の順

## この用語の見どころ

### 1. 役割

Google 製、ターミナルで動く AI エージェントです。

### 2. うれしさ

### 3. 注意点

無料枠には利用回数の上限があります。

### 4. どこで役立つか

### 5. はじめに

npm でインストールし、Google アカウントでログインします。

### 6. 深掘り先

## 開発フローでの位置（必須）

1. インストール — npm で `gemini-cli` を導入します。
2. ログイン — Google アカウントでログインし、無料枠を使います。
3. 指示を出す — 自然言語でファイル編集やコマンド実行を依頼します。
4. 自律実行 — ファイル操作やシェル実行、MCP 連携までこなします。
5. 差分を確認 — 変更内容を人が確認し、必要なら承認します。

## コミュニティ補完メモ

- Gemini（B-1）との住み分け：Gemini はモデル・サービスブランド全体を指します。本エントリはその CLI 版ツールに絞ります
- Claude Code（B-7）との住み分け：どちらもターミナル型のエージェント型ツールです。Gemini CLI はオープンソースで、Google アカウントだけで無料枠から試せる点が異なります
- Codex（B-8）との住み分け：Codex は ChatGPT 組み込みが主体です。Gemini CLI はターミナル起動が前提の点で棲み分けます
- Google AI Studio（B-39）との住み分け：AI Studio はブラウザでの試用や API キー発行が中心です。Gemini CLI はターミナルでの実作業向けです
- MCP（I-1）との住み分け：MCP は外部ツール接続の規格です。本エントリは Gemini CLI がその規格を使う側であることに触れるにとどめます
