# Replit

## tagline

ブラウザだけでコードを書き、そのまま公開まで進められる開発環境です。

<!-- ━━━━━━━━ 左ページ ━━━━━━━━ -->

## 何をしてくれるか

ブラウザを開くだけでエディタ・実行環境・公開先がそろい、環境構築なしでコードを書いて動かせます。その上にある Replit Agent という機能は、指示から実装・テスト・公開までを自動で進めます。

## どこで出会うか

「環境を用意せずすぐ試したい」というときに名前が挙がります。プログラミング学習の教材や、AI にアプリ一式を作らせる系のサービス比較記事でもよく見かけます。

## メイン図

### 図の狙い

ブラウザだけで「書く→動かす→公開する」が一直線につながる様子を示します。

### C. 概念図（figure_type: workflow）

- 中心に置く概念: ブラウザ 1 枚の中で「書く→動かす→公開」が完結する流れ
- 周辺の要素（3〜6個）: エディタ画面、実行結果パネル、公開用の URL、Replit Agent への切り替え口
- 関係の描き方（矢印・包含・比較）: 3 つの工程を左から右へ矢印でつなぎ、その上に Agent への分岐矢印を添える

## この用語の見どころ

### 1. 役割

ブラウザ上でコードを書き、実行し、公開まで済ませる環境です。

### 2. うれしさ

環境構築の手間なく、思いついたらすぐ試せます。

### 3. 注意点

料金は使った分に応じて変わる従量課金へ移行しています。

### 4. どこで役立つか

プロトタイプ作りや学習用のちょっとした実験に向きます。

### 5. はじめに

アカウント登録後、テンプレートから始められます。

### 6. 深掘り先

Replit Agent、デプロイ、AI エージェント

## 開発フローでの位置（必須）

1. ブラウザで開く — アカウント登録後すぐにエディタ画面が開きます。
2. コードを書く — 標準エディタか AI への指示でコードを組み立てます。
3. その場で実行 — ブラウザ内でそのまま動かして確認できます。
4. 公開 — ワンクリックで URL を発行し、そのまま外部と共有できます。
5. Replit Agent へ依頼 — 指示だけで実装からテストまで任せられます。
