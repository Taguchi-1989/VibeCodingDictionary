# Copilot から Claude Code までの流れ

## tagline

補完・チャット・エージェントへと役割を広げてきた開発支援ツールの系譜です。

<!-- ━━━━━━━━ 左ページ ━━━━━━━━ -->

## 何をしてくれるか

GitHub Copilot は 2021 年 6 月プレビュー、2022 年 6 月 GA の行補完ツールです。以後チャット相談、複数ファイル編集を経て、2025 年の Claude Code など自律型エージェントへ役割が広がりました。

## どこで出会うか

エディタの補完候補、チャット相談、ターミナルのエージェントなど、使うツールが流れのどこに立つか確認する場所です。行き着く先は、人が方針を決め、AI が手を動かす役割分担への移動です。

## メイン図

### 図の狙い

2021 年から 2025 年までを時系列で並べ、補完・会話・エージェントという役割の変化を一目で追えるようにします。

## 備考

GitHub Copilot の登場年は情報源によって 2021 年（テクニカルプレビュー）と 2022 年（一般提供）で割れます。本文ではどちらも間違いではないため両方を明記しています。

**著者の指摘（2026-09-06）**: 補完型から**エージェント型**への移行が本質で、**Claude Code はやはり革命だった**と考えている。効いているのは「エージェンティックに自律的に動く」こと、そして**エンドツーエンドで通してやり切れる**こと。

難しいのは言葉のほうで、**この領域を知らない人には「エージェントとは何か」の説明が非常に面倒**。知っている人同士なら「こういう動きができる」で通じるが、そこがごっちゃになりやすい。**用語の説明コストが実際の障壁になっている**という指摘は、本書そのものの存在理由に重なる。H-59 AI エージェント元年、G-49 AI エージェントと合わせて読ませたい。
