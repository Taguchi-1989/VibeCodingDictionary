## 何をしてくれるか

Codex という名前は 2021 年と 2025 年で 2 回登場しました。1 回目は GPT-3 をコード向けに追加学習したモデル、2 回目は自分で作業を進めるコーディングエージェントです。同じ名前でも別物として扱うと理解しやすくなります。

## どこで出会うか

ニュースや解説記事で「Codex」の名前を見るとき、どちらの時代の話かで意味が変わります。GitHub Copilot の初期解説や OpenAI の最新エージェント紹介で名前が重なり、読者が混乱しやすい場面です。

## メイン図

### 図の狙い

2021 年から 2025 年へ続く横軸タイムラインで、Codex という名前が一度消えて別の姿で戻ってきた流れを一望できるようにします。

## 備考

- 2021-08: OpenAI が GPT-3 をコードで追加学習した Codex を公開。初代 GitHub Copilot の中身はこの Codex だった
- 2023-03: OpenAI が API から Codex モデルを提供終了。Copilot の中身は GPT-4 系など後継モデルへ入れ替わっていった
- 2023〜2024 ごろ: 「Codex」はほぼ使われない名前になる
- 2025 年: OpenAI が同じ名前を、自分で作業を進めるコーディングエージェント（Codex CLI など）として復活させた
- 同じ「Codex」という名前でも、2021 年時点はモデル、2025 年時点はエージェントを指しており中身は別物
