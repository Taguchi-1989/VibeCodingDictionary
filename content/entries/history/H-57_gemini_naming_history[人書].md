# Gemini の命名史

<!-- ━━━━━━━━ 左ページ ━━━━━━━━ -->

## tagline

数字は世代、Pro と Flash は同じ世代内での大きさ・速さの違いを表す呼び方です。

## 何をしてくれるか

Gemini の命名史を知ると、モデル名から世代とサイズの見当がつくようになります。数字は世代を、Pro や Flash はその世代内での大きさ・速さの違いを示します。

## どこで出会うか

API のモデル一覧や料金表で、Pro／Flash／Flash-Lite という名前を見かけます。Gemini アプリのモデル切り替えメニューでも、世代とサイズの組み合わせで迷うことがあります。

## メイン図

### 図の狙い

2023 年 12 月の Gemini 1.0 から 3 系まで、世代とサイズ表記の変遷を横軸タイムラインで示します。

## 会話での使い方例

「2.5 Flash は 2.5 Pro と同じ世代で、速さ重視のモデルです。」


<!-- ━━━━━━━━ 右ページ ━━━━━━━━ -->

## この用語の見どころ

### 1. 役割

モデル名の数字＝世代、Pro／Flash＝サイズの読み方を示します。

### 2. うれしさ

モデル名だけで新しさと得意分野の見当がつきます。

### 3. 注意点

世代番号の更新は速く、断定より公式ページの確認をおすすめします。

### 4. どこで役立つか

API 選定やモデル比較記事を読むときに使えます。

### 5. はじめに

Ultra／Pro／Nano という 3 兄弟の考え方が起点です。

### 6. 深掘り先

Gemini 1.5 系、Flash と Pro の違い、Bard → Gemini

## 開発フローでの位置（必須）

1. 名前を見る — API や料金表で見かけます
2. 世代を読む — 先頭の数字が新しさの目安です
3. サイズを読む — Pro は精度、Flash は速さ重視
4. 用途で選ぶ — 精度重視なら Pro、量なら Flash

## 備考

- 2023-12: Gemini 1.0 発表。Ultra／Pro／Nano という「大きさ違いの 3 兄弟」の考え方が示された
- 2024 年: 1.5 系で扱える文脈（コンテキスト）の量が大きく広がった
- 2.0 系以降: 速さ重視の Flash、さらに軽い Flash-Lite という呼び名が定着し、Ultra は前面に出なくなった
- その後 2.5 系、3 系と続く。数字は「世代」、Pro／Flash は「同じ世代の中での大きさ・速さの違い」を表す
- 世代番号は更新が速い領域のため、evaluation_date（2026-08-10）以降の新世代は本エントリに反映されていない。そのときどきの一覧は Google DeepMind の公式ページで確認が必要
