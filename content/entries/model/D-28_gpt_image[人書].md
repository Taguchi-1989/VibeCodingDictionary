# GPT Image 系

## tagline

ChatGPT の絵を描く OpenAI の画像モデル系統で、DALL-E の後継です。

<!-- ━━━━━━━━ 左ページ ━━━━━━━━ -->

## 何をしてくれるか

文章や参照画像を渡すと、画像を生成・編集します。絵専用の別モデルではなく、会話するモデルの系統が絵も描く形で、版を重ねて機能が増えています。

## どこで出会うか

ChatGPT や Codex で絵を頼むと、2025 年 3 月以降はこの系統が動きます。API ではモデル名に「GPT Image」と現れ、版ごとに使える機能が違います。

## メイン図

### 図の狙い

DALL-E 3 から GPT Image 1、1.5、2、2.5、2.6 へと続く流れを 1 本の年表で見せ、「ChatGPT で絵を頼むと動くのは、今は DALL-E ではなく GPT Image」だと掴んでもらう。

### A. タイムライン（figure_type: timeline）

- 2023-10：DALL-E 3（ChatGPT に統合）
- 2025-03：GPT Image 1（ChatGPT で DALL-E 3 を置き換え）
- 2025-12：1.5 ／ 2026-04：2 ／ 2026-09：2.5
- 2026-11：2.6（動く GIF の生成、参照画像の保存。API は Flare と Sunburst の 2 本）

## 会話での使い方例

「ChatGPT で絵を頼むと、今は DALL-E ではなく GPT Image が動くんですよね。」
