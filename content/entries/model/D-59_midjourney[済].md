# Midjourney

## tagline

文章から画像を生成するサービスで、絵として整った独特の作風の強さで知られます。

<!-- ━━━━━━━━ 左ページ ━━━━━━━━ -->

## 何をしてくれるか

文章の指示文（プロンプト）を送ると、絵として整った質感の高い画像を生成します。もともとは Discord 上でコマンドを打って使う形式で広まり、現在は Web 版でも操作できます。

## どこで出会うか

画像生成の話題で真っ先に名前が挙がるサービスです。デザイナーやクリエイターの SNS 投稿、広告やコンセプトアート作りの現場で見かけます。

## メイン図

### 図の狙い

Midjourney への入り口が Discord と Web の 2 通りあり、どちらもプロンプトを渡すと同じ画像生成の仕組みにつながることを一目で掴んでもらいます。

### C. 概念図（figure_type: structure）

- 中心に置く概念: プロンプトから画像を作る Midjourney 本体
- 周辺の要素（3〜6個）: Discord コマンド、Web 版、4 枚の候補画像、アップスケール
- 関係の描き方（矢印・包含・比較）: Discord と Web の 2 入口から中心へ矢印、中心から候補画像へ矢印、候補画像からアップスケールへ矢印

## 開発フローでの位置（必須）

1. Discord か Web で始める — サーバー参加か Web 版を開きます。
2. プロンプトを書く — 画風・構図・比率をパラメータで指定します。
3. 生成・選定 — 提示された 4 案から 1 枚を選びます。
4. アップスケール — 選んだ案を高解像度化し微調整します。
5. 利用規約を確認 — 商用利用条件やライセンスを確認します。

## コミュニティ補完メモ

- DALL-E（D-50）との住み分け：DALL-E は ChatGPT 統合の閉じた API 型で無料枠もある入口。Midjourney は無料枠がなく、絵作りの完成度の高さで選ばれる点を対比軸にする
- Stable Diffusion（D-54）との住み分け：SD はウェイト公開で手元改造が前提。Midjourney は非公開のクローズ型サービスとして対比する
- Discord（B-42）との関係：Midjourney は「Discord 上での操作が入口だったサービス」の代表例として B-42 側から参照される想定。本エントリでは Discord の仕組み自体の説明は 1 文に留め、詳細は B-42 に譲る
- 拡散モデル（J-23）との関係：仕組みの深掘りは J-23 に委ね、本エントリでは触れない
