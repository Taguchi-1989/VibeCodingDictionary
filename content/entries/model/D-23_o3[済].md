# o3 系

## tagline

答える前にじっくり考える、o1 系の後継にあたる推論モデル系です。

<!-- ━━━━━━━━ 左ページ ━━━━━━━━ -->

## 何をしてくれるか

o1 系の後継にあたる推論モデル系で、o3-mini・o3・o3-pro の 3 段階があります。o3-mini は費用と速さ重視、o3 は汎用の推論力向上版、o3-pro は道具も使える最上位です。

## どこで出会うか

ChatGPT（B-3）や API のモデル選択画面で、2025年1月31日に o3-mini、4月16日に o3、6月10日に o3-pro が登場しました。o3-pro は料金も待ち時間も高めです。

## メイン図

### 図の狙い

o3-mini・o3・o3-pro を並べ、費用と待ち時間の違いを一目で示します。

### A. 比較（figure_type: comparison）

- o3-mini: 軽量・低コスト → 科学・数学・コーディングの速い確認向き
- o3: 汎用の推論強化版 → 難しい実務タスクの精度重視
- o3-pro: 最上位・長考型 → Web 検索やファイル解析、Python 実行も使う深掘り向き

## 会話での使い方例

「重い処理は o3-pro、軽めの確認は o3-mini で使い分けています。」

**著者の指摘（2026-09-06）**: 当時は最先端で「すごい」と言われた。MMLU のようなベンチマークのスコアが上がって飽和していく一方、Humanity's Last Exam は一桁で「まだまだ難しいこともある」と言われていた。**今はそこも越えていってしまうので、レガシーとして読む対象**。特にサーチ系・Deep Research の強さは印象に残っている。

### 「なぜコストが高かったのか」の調べ物（2026-09-06）

著者から「アテンション機構や KV キャッシュの扱いが発展途上でコストが高かったのでは」という仮説が出たので調べました。**結論としては、主因はそこではありませんでした。**

- **主因は「考えた分だけ出力トークンを使う」こと**です。見える答えが 100 トークンでも、内部の思考が 2,000 トークンということが起こります。**課金されるのは思考のぶんも含めた出力**なので、そのまま料金になります
- **test-time compute の量そのものが桁で動きます。**ARC-AGI に対して **o3 の high 設定は low 設定の 172 倍の計算**を使ったと報告されており、1 問あたり 3 万ドル規模という試算も出ました
- 価格でも o1-pro / GPT-4.5 が出力 100 万トークンあたり 600 ドルだったのに対し、Claude 3.5 Sonnet は 15 ドル。**40 倍の開き**があります
- 副次的な影響としてベンチマーク自体が高額になりました。推論モデル十数個の評価に約 5,200 ドル、非推論モデル 80 個超の評価（約 2,400 ドル）の 2 倍以上

**アテンションや KV キャッシュの効率化は、この「長く考える」コストを緩和する側の技術**です。当時それが未成熟だったのも事実ですが、**高コストの直接の原因は思考トークンの量**でした。著者の仮説は方向としては関連しますが、主従が逆です。
