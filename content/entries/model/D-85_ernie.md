# ERNIE 系

## tagline

Baidu が 2019 年から続けるモデル群です。一部は重みも公開されています。

<!-- ━━━━━━━━ 左ページ ━━━━━━━━ -->

## 何をしてくれるか

Baidu が 2019 年から開発するモデル群です。初期は言語理解の研究でしたが、2023-03 に対話 AI の ERNIE Bot となり、2025 年から一部の重みも公開されました。

## どこで出会うか

オープンモデルの比較や、中国勢の動向の話題で名前が出ます。ERNIE 4.5 は Apache 2.0 で公開され、2026-11 に新しい版の重み公開が予定とされています。

## メイン図

### 図の狙い

研究から対話 AI、さらに重み公開へと続く年表を見せ、「API だけの版」と「重みを配る版」が混在する流れを掴んでもらいます。

### C. 概念図（figure_type: timeline）

- 中心に置く概念: ERNIE の年表（2019 → 2023 → 2025 → 2026）
- 周辺の要素: ERNIE 1.0、ERNIE Bot、ERNIE 4.5 の重み公開、5 系の API 提供、2026-11 の公開予定
- 関係の描き方: 横軸の年表に、「重みを配った版」の目印と「API のみの版」の目印を色分けして置く

## この用語の見どころ

### 1. 役割

Baidu 製で、API と重み公開の両方がある系譜です。

### 2. うれしさ

一部の版は Apache 2.0 で、自由に使えます。

### 3. 注意点

版ごとに重みの公開やライセンスが違います。

### 4. どこで役立つか

オープンモデルの選択肢を広げる比較です。

### 5. はじめに

年表で、どの版が公開されたかを見ます。

### 6. 深掘り先

Baidu、オープンモデル、MoE

## 開発フローでの位置（必須）

1. 系譜を知る — 2019 年からの流れを年表でつかむ
2. 版を選ぶ — API のみの版か重み公開の版かを分ける
3. ライセンス確認 — 版ごとの条件を公式で確かめる
4. 並べて試す — DeepSeek など他のオープンモデルと比べる
5. 予定を追う — 公開予定は公式の発表で確認する
