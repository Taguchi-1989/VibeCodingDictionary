# Jev

## tagline

TypeSafe AI が出した、文章を書かず型と確率で答える判断専用モデルです。

<!-- ━━━━━━━━ 左ページ ━━━━━━━━ -->

## 何をしてくれるか

選択肢から 1 つ選ぶ、度合いに点をつける、はい／いいえの確率を出す、の 3 つだけを担う判断専用モデルです。答えは文章ではなく型のついた値で返り、出力は 2026-11 時点で無料です。

## どこで出会うか

エージェントの交通整理（どの担当に回すか）、問い合わせの緊急度判定、通してよいかの判定などで使われます。TypeSafe の API や公式 SDK、一部のゲートウェイ経由で呼びます。

## メイン図

### 図の狙い

LLM は文章で答え、Jev は型と確率で答える違いを並べて見せます。出力の形が小さく決まっていることが伝わるようにします。

### B. 比較図（figure_type: comparison）

- 左「LLM：文章で答える」: 数秒かかり、出力にも課金される
- 右「Jev：型と確率で答える」: 1 秒未満で、出力は無料。例 `{ route: "請求", 緊急: 0.93 }`
- 例示ラベル: 「2026-11 時点」。決めるのはコード側

## 会話での使い方例

「Jev は文章を書かず、型と確率だけ返す判断役ですよね。」

## この用語の見どころ

### 1. 役割

文章を書かず、判断だけを返す専用モデルです。

### 2. うれしさ

小さな判断を、速く安く大量に回せます。

### 3. 注意点

型は崩れませんが、中身は間違えます。理由も言いません。

### 4. どこで役立つか

振り分けや分類など、答えの候補が決まった判断です。

### 5. はじめに

問い合わせの分類など、小さな判断 1 つから試します。

### 6. 深掘り先

Structured Outputs、モデルルーティング

## 開発フローでの位置（必須）

1. 判断を切り出す — 文章がいらない小さな判断を探す
2. 質問の型を選ぶ — Choice・Score・Noul から合うものを選ぶ
3. Jev に質問する — 状態と質問を渡し、型つきの値を受け取る
4. コードで決める — しきい値を決めて分岐するのはコード側
5. 結果を見直す — 間違いやすい例を集めて質問文を直す

## 備考

- **全項目が一次未確認**：typesafe.ai は環境の許可ホストになく直接取得できず、すべて検索経由（二次情報を含む）です（2026-11-13 時点）。数字は TypeSafe の自社発表が出どころで、第三者の検証は乏しい状況です
- 読みは「ジェブ」と表記している日本語記事に合わせました。公式の読みは未確認です
- 位置づけ：同社は判断だけを担うこの種類を「System One モデル」と呼び、名前はカーネマンの「システム 1（速い直感）／システム 2（遅い熟考）」から。LLM を熟考役、Jev を即断役に見立てます。合言葉は「Jev makes judgments, code makes decisions」
- 創業者は Diogo Almeida 氏（元 OpenAI の研究者・エンジニアと報じられる。日本語記事では「ChatGPT の共同開発者」という紹介もある）。2 年のステルス期間を経て、DCVC 主導の 4,000 万ドルのシード調達と同時に発表と報じられています
- 質問の型：Choice（選択肢から 1 つ。確率分布と confidence つき）／Score（度合いを数値で）／Noul（命題が真である確率 0〜1。0.5 は「どちらとも言えない」で、はい／いいえに変えるしきい値はアプリ側のコードが決める）。複数の質問を 1 回の並列処理で答えます
- 料金：入力 100 万トークンあたり $0.042、出力は無料（2026-11 時点、各社の解説記事）。質問文や選択肢の説明は入力として数えられ、出力トークン数は利用量に報告されるが課金されないとされます
- 速さ・安さ（自社発表の数字）：応答 70〜500 ミリ秒。同社は先端 LLM より 40〜200 倍速い（193 倍という数字も）、40〜400 倍安い（445 倍という数字も）と主張。誌面本文には出していません
- 仕様：文脈 32,000 トークン。学習は合成データのみで、同社が RLCD（Reinforcement Learning for Calibrated Decisions）と呼ぶ手法。構造は非公開（オープンウェイト LLM が土台ではないかという外部の推測あり）
- 版：jev-1.13.0（公開時）→ jev-1.14.0（2026-10-14、`jev-latest` はこれを指す）
- 使える場所：TypeSafe の API（`POST api.typesafe.ai/v1/systemone`）と公式 Python / JavaScript SDK。OpenRouter・Vercel AI Gateway・Cloudflare にも掲載があると報じられています。Amazon Bedrock には無いとされます
- **提供状況は情報が割れています**：2026-09-20〜21 ごろに順番待ちを外したという報道と、一般提供（SLA つき）の日付は未公表という記述が併存。無料クレジット（$5）の有無も食い違い。本文は「早期アクセスで公開（2026-09-15）」の範囲にとどめ、version_status は active としました
- 弱み（同社文書と第三者レビュー）：存在しない選択肢は返さないが、間違った選択肢を高い確信度で返すことはある（Armin Ronacher 氏の評）。理由を説明しないため、採用選考のような説明が要る判断には向かない（EU AI Act の高リスク領域という指摘）。数える・計算・日付の比較が苦手、文字どおりに解釈しがち、選択肢の並び順に左右されることがある、悪意ある入力を既定では疑わない
- ベンチマークは自社実施：4 種の業務フローで 67.8%（比較対象の LLM は 74.1%）。正解との照合ではなく「先端 LLM と答えが一致するか」で測定。独立した第三者ベンチマークは未確認
- 類似名の非公式サイト（jevtypesafe.org など）は公式ではありません
- 同種の「判断モデル」（Liquid d1 など）も名前が挙がり始めている（二次情報）
- 価格・版数・提供状況は時変情報です。次回の鮮度監査で確認してください
