## 生成・整形

- Built-in `image_gen` を使用。既存 `J-103.webp` をスタイル参照にした。
- 白地、濃紺線画、淡青アクセント、余白多め、横長 2:1 を共通条件にした。
- 画像内に読ませる日本語は置かず、ラベルは誌面側の本文・HTMLへ任せる。
- 元生成 PNG は `*_raw.png`、誌面候補は `{id}_*.png` と `{id}_*.webp`。
- 候補 PNG/WebP は 1254×627 に正規化済み。
- 機械監査は `image_audit.md` / `image_audit.csv`、一覧確認は `contact_sheet.webp`。
